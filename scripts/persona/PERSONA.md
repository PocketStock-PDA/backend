# 페르소나 / 시연용 목데이터 (demo1~demo10)

시연·테스트용 목 데이터. SSOT는 SQL 시드:
`scripts/mysql-a-persona-seed.sql`(DB A) · `scripts/mysql-b-persona-seed.sql`(DB B).
docker initdb `03-persona-seed.sql`로 마운트되어 빈 볼륨 첫 기동/`down -v` 후 1회 적재된다.

> 이 디렉터리의 `db-a-*.csv` / `db-b-*.csv`는 구버전(3페르소나) 표현으로 더 이상 적재되지 않는다. 현재 기준은 위 SQL 시드.

## 두 묶음 구성

- **demo1~5 — 즉시 시연용(준비 완료)**: 온보딩·자산연동·계좌 개설(CMA+종합)까지 끝난 일반 사용자.
  CMA에 **약 1,000만원** 예치 → 로그인 직후 매매·투자 즉시 가능. 다섯 계정 모두 동일하게 풍부하며 이름만 다르다.
  어느 계정으로 들어가도 막히는 기능이 없다.
- **demo6~10 — 케이스 테스트용(분기 결손)**: 서비스 여정 중 한 단계가 비어 있는 계정.
  계좌 개설은 CMA·종합계좌가 함께 열리므로 "둘 다 있음 / 둘 다 없음"으로만 구성한다.
  홈 진입 전 과정(가입→연동→스캔→계좌 개설)은 onboarding 한 덩어리로 본다.

## 데이터 구성 요약(공통)

**DB A (연동 보유 계정 = demo6 제외 전원)**
- 연동 기관 6종: 신한은행 / 신한카드 / 마이신한포인트 / 국민은행 / 카카오뱅크 / 토스증권
- 은행 5계좌: 신한 입출금·신한 정기예금(3.8%)·국민 입출금(휴면)·카카오뱅크 입출금·SOL트래블 외화예금(USD)
- 카드 2장(신한 체크/신용), 마이신한포인트, 토스증권 예수금 + 타사 보유(삼성전자·SK하이닉스)
- 카드내역 12건(2026-05~06), 가계부 목표 6카테고리(2026-06), 보유종목 복제본(삼성전자·SK하이닉스)
- 전 계정: 약관 동의 2건, 계좌 비밀번호(1234), 알림 설정

**DB B (계좌 개설 계정 = demo1~5,8,9,10)**
- CMA 계좌 + 원화풀(완비/9/10 = 1,000만, demo8 = 0) + 달러풀(완비 계정 USD 250)
- CMA 거래내역(초기 입금 + 카드/계좌/포인트 수집 + 이자, 누적 = 잔액)
- 잔돈 수집 설정 3종(ACCOUNT/CARD/POINT), 자동충전 설정
- 종합계좌(국내/해외) + 예수금 잔액(0), 보유종목(삼성전자·SK하이닉스), 자동투자 설정(+정기매수 종목)

> demo8은 계좌만 열려 있고 CMA가 비어 있어 "수집→매수" 첫 경험을 시험한다.
> demo7은 계좌 자체가 없어 "계좌 개설"을 시험한다(둘은 코드의 CMA·종합 동시개설 동작과 일치).
